# Arquitetura Zero Trust
Este repositório contém um trabalho realizado para a unidade curricular Sistemas de Comunicações e Redes (Licenciatura em Ciência da Computação, Universidade do Minho).

# Sobre o trabalho
O trabalho estuda a Arquitetura Zero Trust (ZTA), um paradigma de segurança de redes que substitui o modelo tradicional baseado em perímetro pelo princípio "nunca confiar, verificar sempre". Aborda o conceito de confiança em cibersegurança, o modelo lógico do NIST (SP 800-207), os pilares técnicos da arquitetura (autenticação, controlo de acesso e avaliação contínua de confiança), alguns domínios de aplicação e os principais desafios de implementação.
